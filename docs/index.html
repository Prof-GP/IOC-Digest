CVE-2026-85706 — max-severity GitLab path traversal in the commits API added to KEV under emergency directive

GitLab's repository commits API has an improper path-confinement and missing-authentication flaw, CVE-2026-85706 (CVSS 10.0), that lets an unauthenticated attacker read arbitrary files from an affected self-managed GitLab server under certain conditions. CISA added it to KEV Sep 11 with confirmed active-exploitation evidence, invoking emergency federal directive BOD 26-04 requiring immediate patching outside the normal cycle rather than the standard deadline window. GitLab.com and GitLab Dedicated were already patched before disclosure; affected self-managed versions span 18.7 through 19.3.1. No public IOCs (attacker IPs, request signatures) accompanied the advisory. Durable catch: an unauthenticated arbitrary-file-read against a self-managed GitLab instance can pull CI/CD secrets, SSH keys, or config files straight off the server — treat this as a credential-exposure incident requiring rotation, not just a patch-and-move-on vulnerability.

CVE-2026-20079 — max-severity Cisco Secure FMC auth bypass exploited by Sandworm and Qilin to drop web shells

Cisco confirmed active exploitation of CVE-2026-20079, a CVSS 10.0 authentication bypass in Secure Firewall Management Center's web interface that lets an unauthenticated remote attacker execute scripts and commands as root. Cisco Talos tracked three distinct post-compromise clusters — UAT-12197, UAT-11823, and UAT-11988 — with UAT-12197 dropping a JSP web shell into the FMC's Tomcat webroot that decodes a parameter and loads a Java class into the running process, alongside a JAR-based command executor and credential exfiltration; reporting attributes exploitation to both Sandworm and Qilin-linked activity. CISA added it to KEV as part of a Sep 10 batch with Cisco NetScaler and Fortinet, setting a Sep 12 federal patch deadline. Durable catch: any unexpected .jsp file appearing in an FMC's Tomcat webroot, or an unfamiliar JAR file sitting alongside it, is a near-certain sign of this specific exploitation chain — check that path first, before broader log review.

A Russian-speaking-attributed campaign has been exploiting CVE-2025-25249, a heap-based buffer overflow in FortiOS, FortiSwitchManager, and FortiSASE (CVSS 7.3), to deliver the PivotC2 remote-access trojan via crafted requests, with exploitation evidence dating back to July 2026. 'StyleSmuggler' — CVE-2026-75650 lets attackers turn Adobe Commerce's own template engine into unauthenticated RCE

Sansec disclosed CVE-2026-75650 ('StyleSmuggler'), a CVSS 10.0 unauthenticated RCE affecting Adobe Commerce 2.4.4-2.4.9 and Magento Open Source 2.4.6-2.4.9, where an attacker injects PHP through Magento's email-template system by exploiting the fact that style properties are treated as harmless layout data and pass through template safeguards unchecked — the payload then rides Magento's own dependency-injection machinery into execution. Sansec observed active exploitation beginning Sep 4, three days before Adobe's out-of-band patch shipped Sep 7; CrowdSec has tracked 500 unique IPs sending matching requests since Sep 9, and 23 of the 410 addresses probing StyleSmuggler also tried last year's SessionReaper flaw (CVE-2025-54236) — the same actor set revisiting Magento. Durable catch: exploitation began three days before a patch existed — any Magento/Adobe Commerce store that applied hotfix VULN-39341 without also checking for a planted backdoor from that pre-patch window should assume compromise, not just apply the fix and move on.

CVE-2026-86218 — pre-auth RCE in N-able N-central RMM exploited, fourth patch in five weeks

N-able confirmed active exploitation of CVE-2026-86218 (CVSS 10.0), a static code injection flaw (CWE-96) in N-central that lets an unauthenticated attacker send crafted requests the server evaluates without validation, executing arbitrary OS commands as root with no authentication or user interaction required. Because N-central is an RMM platform used by managed service providers, a compromised instance is a foothold into every downstream endpoint that MSP manages, not just the N-central server itself; researchers note it can potentially be chained with two authentication-bypass flaws (CVE-2026-86206, CVE-2026-86207) to bypass console auth and create attacker-controlled admin accounts. CISA added it to KEV Sep 8; it was patched in N-central 2026.3 Hotfix 4 on Sep 5, marking N-able's fourth patch to the product in five weeks. Durable catch: N-central's role as an RMM makes this a supply-chain-shaped vulnerability — any MSP running an unpatched instance should assume every client endpoint it manages is in the blast radius, not just the RMM server.

Microsoft's record 964-CVE Patch Tuesday includes two actively exploited Windows zero-days

Microsoft's September Patch Tuesday addressed 964 CVEs — a record volume — including two zero-days confirmed exploited in the wild: CVE-2026-81963, an improper link-resolution ('link following') flaw in the Windows Update Stack that is the first such component to be exploited as a zero-day since 2022, and CVE-2026-85880, a heap-based buffer overflow in Windows ALPC. Both are elevation-of-privilege bugs rated CVSS 7.8 that let an attacker with initial local access escalate to SYSTEM, turning an initial foothold into full device control; CISA added both to KEV Sep 8 with a Sep 22 federal remediation deadline. No public IOCs (samples, attacker groups) were disclosed alongside either advisory. Durable catch: both zero-days require local access to start — they're the second stage of an intrusion that began another way, so patching them closes the escalation path but doesn't address however the attacker got a foothold in the first place.

Veradigm discloses patient data breach after The Gentlemen ransomware gang claims 3.5 million records via vendor API

Healthcare technology firm Veradigm disclosed that stolen login credentials within a third-party vendor's environment granted unauthorized access to a Veradigm API used for service delivery, which the attacker used to download patient records; Veradigm says the breach was contained to that vendor-facing interface with no disruption to internal systems and no clinical/medical data exposed. The Gentlemen ransomware-as-a-service gang added Veradigm to its leak site Sep 5, claiming 3.5 million patient records including names, addresses, phone numbers, email addresses, and other PII, including Social Security numbers for a subset of customers. Durable catch: the attacker never touched Veradigm's own network — stolen vendor credentials against a narrow, purpose-built API endpoint were sufficient to reach 3.5 million patient records, which is the actual lesson for any organization exposing a vendor-facing API scoped to 'just' service delivery.
