Metabase SQL-injection 0-day (GHSA-vwf4-m7j8-wcjf) — unauth admin takeover

An unauthenticated remote attacker can inject arbitrary SQL into the Metabase application database and mint administrator access, then read connected-database credentials and export data. Exploited in the wild before a fix; n8n disclosed an attacker used it to pull 136 customer records. CVSS 10.0. Durable catch: a POST to /api/session/reset_password returning 400 immediately followed by a GET /api/user/current returning 200 — the reset-password injection signature.

CVE-2026-63077 — JetBrains TeamCity unauthenticated deserialization RCE

On-prem TeamCity exposes unauthenticated RCE through the agent polling protocol: a permissive XStream allowlist adds TeamCity protocol classes without removing XStream's default permissions, so untrusted data deserializes into code execution. CISA added it to KEV (federal deadline Aug 8) and a public PoC writes .JSPWS files to run commands. CVSS 9.8. Durable catch: unexpected .JSPWS files under the TeamCity web/work directories and agent-protocol requests from hosts that are not build agents.

CVE-2026-68820 — Windows afd.sys use-after-free, SYSTEM privilege escalation

A use-after-free in the Ancillary Function Driver for WinSock (afd.sys), the kernel-mode backbone of the Windows Sockets API, lets a locally authenticated attacker win a race condition and elevate to SYSTEM. Exploited in the wild as a zero-day and fixed in the Aug 11 Patch Tuesday, where Microsoft shipped 421 CVE fixes. Local EoP is the pivot after initial access — patch is the fix; also close CVE-2026-62832 (publicly-disclosed User Profile Service EoP) in the same batch.

CVE-2026-9198 — Langflow unauthenticated RCE mints SUPERUSER tokens

In Langflow OSS 1.0.0-1.10.0 the /api/v1/auto_login endpoint is neither authenticated nor loopback-bound, so any network caller is issued a SUPERUSER token and can chain a second API endpoint to unauthenticated RCE. It is the first AI-agent platform added to CISA KEV (Aug 4); KEVIntel logged ~650 exploitation attempts from 244 IPs across 41 countries since Jul 6. Durable catch: any external hit to /api/v1/auto_login — Langflow stores model, database and connector credentials, so RCE means full secret exposure.
