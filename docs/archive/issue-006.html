CVE-2026-18431 — Avada theme's 6-step exploit chain lets unauthenticated attackers run PHP on 1M+ WordPress sites

Argus found and reproduced a chain of six authorization, input-validation, trust-boundary, and file-handling weaknesses in the Avada theme and Fusion Builder plugin that, executed in a specific order, let an unauthenticated attacker achieve arbitrary PHP code execution with zero clicks. GPUThor Rowhammer attack defeats ECC on NVIDIA RTX A6000, achieves host root shell

University of Toronto researchers disclosed GPUThor, the first Rowhammer-class attack to break through NVIDIA's ECC protections on workstation GPUs. On an ECC-enabled RTX A6000, the attack forces a GPU reset every 2 hours (killing running jobs and eventually flagging the card RMA-ready) and, by corrupting GPU page tables, lets an unprivileged GPU program escalate to a root shell on the host CPU in under two minutes — the first such takeover of an ECC-protected GPU. The researchers disclosed to NVIDIA in April 2026 and held the work under embargo until NVIDIA published mitigation guidance Aug 25; no CVE has been assigned and no in-the-wild exploitation is known. Durable catch: ECC alone is no longer sufficient GPU-sharing isolation — any environment running untrusted or multi-tenant GPU workloads on affected hardware needs an additional control, not just ECC-enabled status, before treating cross-tenant isolation as solid.

REPORTED 2026-08-27ACTIVE SINCE 2026-08-25 FIRST ROWHAMMER TO DEFEAT NVIDIA ECC ROOT SHELL ON HOST CPU IN UNDER 2 MINUTES T1068 · T1611 The Hacker News (Aug 27) · BleepingComputer

24 npm packages abuse unpkg mirror infrastructure to host fake Cloudflare CAPTCHA / ClickFix phishing pages

OX Security found 24 npm packages, published between Aug 4-24, that don't infect installers directly — instead each carries a single HTML file imitating a Cloudflare verification screen, hosted for free via unpkg.com's mirror URLs so the phishing page inherits a trusted domain's reputation. Visitors following a mirrored package link land on the fake CAPTCHA, which redirects to attacker infrastructure for credential harvesting or ClickFix-style clipboard-hijack instructions; the operators initially used a typosquat domain (login[.]microsofte[.]live) before switching to a KeyVal dead-drop resolver after the typosquat got blocklisted. Each package drew only 50-300 weekly downloads before removal. Durable catch: any unpkg.com URL path resolving to one of these 24 package names, or a redirect chain through api[.]keyval[.]org, is this specific campaign regardless of which npm package a victim thinks they clicked into.

South Korean government startup platform exposes personal data after encryption key shipped inside its own API
