CVE-2026-65400 — macOS Screen Sharing pre-auth RCE deploys Monero miners

A flaw in Screen Sharing's Secure Remote Password implementation lets a remote attacker on the network authenticate with no valid credentials and gain full control — pre-auth RCE on every supported macOS version. Apple issued an emergency patch Aug 6; by Aug 14 an advisory confirmed active exploitation on internet-exposed hosts (port 5900 reachable), with attackers obtaining root and planting a Monero miner in every confirmed case. Standard hardening (removing approved users, rotating VNC passwords) doesn't help — it operates downstream of the bypassed authentication step. Durable catch: port 5900 reachable from the internet plus an unexplained Monero-mining process — patch or disable Screen Sharing, don't just rotate credentials.

CVE · EXPLOITED · macOS RCE
ACTION Patch to macOS Tahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9 immediately, or disable Screen Sharing entirely if you cannot patch; never expose port 5900 to the internet; hunt for unexpected Monero-mining processes as a compromise indicator on any host that had Screen Sharing enabled and reachable.

CVE-2026-59310 — VMware vCenter Syslog Server directory traversal, active reverse-SSH campaign

A directory-traversal flaw in vCenter's Syslog server (CVSS 9.8) lets a network-adjacent attacker execute arbitrary code with no authentication. Exploitation began roughly five days after Broadcom's advisory and has now hit 361 victim IPs across 47 countries, with attackers deploying reverse_ssh, an open-source Go reverse-shell tool, via a malicious cron job for persistent access. Durable catch: outbound cron-triggered connections from vCenter appliances and any reverse_ssh process on a vCenter host — there is no vendor workaround, only the patch.

CVE-2026-55040 — SharePoint forged-JWT auth bypass, exploited within 48 hours of PoC

A flaw in SharePoint's JWT validation pipeline accepts a token with alg:none, resolves a signing key from an actor-token x5t header that points at SharePoint's own STS certificate, then never verifies the resulting signature — letting an unauthenticated attacker impersonate any known site user or admin. Rapid7 published exploitation technical details Aug 11; honeypot firm Defused recorded live attempts the next day, with KEVIntel logging 8 of its 12 total attempts in the 48 hours after disclosure. Chained with CVE-2026-63520 it becomes unauthenticated RCE. Durable catch: a JWT with header alg:none and a non-empty but unverifiable signature (e.g. AAAA) presented to SharePoint's STS.

REPORTED 2026-08-12ACTIVE SINCE 2026-07-14 CVSS 9.1 · FORGED-JWT IMPERSONATION 8/12 EXPLOIT ATTEMPTS IN 48H POST-POC T1190 · T1078 · T1550 Hacker News write-up (Aug 13) · SecurityWeek (Aug 13)
CVE · EXPLOITED · AUTH BYPASS
ACTION Confirm SharePoint is patched to 16.0.19725.20434 (Subscription/KB5002882), 16.0.10417.20175 (2019/KB5002883), or 16.0.5561.1001 (2016/KB5002891); hunt STS logs for alg:none JWTs and unexpected admin-identity assertions; treat any farm that was unpatched through mid-August as potentially compromised.

CVE-2026-71362 — Adobe Commerce/Magento session-identity flaw, exploited within hours

Adobe Commerce and Magento Open Source fail to correctly bind a customer's identity to their account session, letting an unauthenticated attacker switch a live session to another customer's account and read their PII and order data. Adobe shipped an isolated patch (APSB26-92) on Aug 11; Sansec's Shield WAF was already blocking exploitation attempts within hours of the advisory going public. Durable catch: unexplained session-identity switches in Magento's customer session store — investigate any account-data access that doesn't match the authenticated session's login.

CVE-2026-20349 — Cisco ASA/FTD SSL VPN heap-inspection DoS, added to KEV

Insufficient error checking in Cisco ASA and FTD's Remote Access SSL VPN service lets an unauthenticated remote attacker send a crafted HTTP request that forces the device to reload — a zero-credential denial-of-service against the perimeter. Cisco disclosed and confirmed active exploitation Aug 11; CISA added it to KEV the same day alongside the already-tracked afd.sys and Metabase CVEs. No workaround exists. Durable catch: unexpected device reload/crash-traceback log events paired with a burst of over 200 connections/minute to the SSL VPN interface.

PicMo Group ransomware — randomized extensions, shadow-copy wipe

A newly-discovered double-extortion Windows ransomware that encrypts files under randomized names and extensions, drops a "How to Restore Your Files.txt" note, and deletes Volume Shadow Copies via vssadmin.exe Delete Shadows /all /quiet and wmic shadowcopy delete /nointeractive before demanding cryptocurrency payment. CYFIRMA published a Sigma rule. Durable catch: the shadow-copy-deletion command pair plus the distinctly-named ransom note — the encrypted-file extension itself varies per run, so don't rely on it.
