CVE-2026-104286 — FortiMail path-traversal zero-day exploited in the wild with no patch available, only a workaround

Fortinet confirmed active exploitation of CVE-2026-104286 (CVSS 9.8), a path-traversal and NULL-byte handling flaw in FortiMail that lets an unauthenticated attacker write arbitrary files via crafted HTTP(S) requests, potentially leading to remote code execution, full system compromise, and lateral movement. CISA added it to KEV Oct 1 with an Oct 4 deadline to apply a workaround, not a patch — as of this writing, Fortinet had not yet shipped a fix for the affected FortiMail 7.2.0-8.0.1 range, only interim mitigation guidance. Durable catch: a KEV deadline requiring a workaround rather than a patch is itself the signal that this flaw is more urgent than a typical CVSS 9.8 — treat 'no patch available' as a reason to apply the workaround immediately rather than waiting for a more complete fix.

CVE-2026-76504 — URI-encoding trick bypasses Cisco Catalyst SD-WAN Manager authentication for full admin API access

Cisco Catalyst SD-WAN Manager's authentication rule for a privileged API endpoint performs a literal string match on the request path without normalizing encoded characters first — so a request to the encoded path /%6a_security_check doesn't match the protected string, the rule silently skips authentication, and the underlying API processes it as if a valid admin session existed. CVE-2026-76504 (CVSS 9.8) requires no credentials or user interaction; Cisco became aware of exploitation in September and published its advisory Sep 30, the same day CISA added it to KEV. Cisco states no workaround exists — patching is the only fix, across version branches from 20.9 through 26.2. Durable catch: the vulnerability is specifically in how the auth rule matches the path string before decoding — any WAF or proxy sitting in front of SD-WAN Manager that normalizes URI encoding before forwarding requests would have independently blocked this, which is worth checking regardless of patch status.

CVE-2026-86950 — Apple CoreGraphics zero-day weaponized against specific individuals via crafted image/document files

Meta's Product Security team reported CVE-2026-86950, an out-of-bounds write in Apple's CoreGraphics framework that triggers when the system processes a maliciously crafted image or document, letting an attacker achieve arbitrary code execution on versions before iOS 27. Apple confirmed the flaw was exploited in 'an extremely sophisticated attack against specific targeted individuals' — language consistent with commercial-spyware-grade targeting rather than broad criminal exploitation. CISA added it to KEV Sep 29 with an Oct 2 federal deadline; Apple shipped fixes across iOS 26.7.1, iPadOS 26.7.1, macOS Tahoe 26.7.1, and macOS Sequoia 15.8.1. Durable catch: a file-processing zero-day discovered by another company's security team (Meta, not Apple itself) targeting specific individuals is the classic signature of spyware-vendor tradecraft — high-risk individuals (journalists, dissidents, executives) should treat this patch as time-sensitive regardless of whether they believe they're personally targeted.

Pentagon confirms breach of personnel database exposing data on 3 million living and deceased service members

The Pentagon confirmed unauthorized access to a Defense Manpower Data Center (DMDC) system that occurred between October 2025 and July 2026, exposing names, dates of birth, Social Security numbers, job specialties, and other records for approximately 2.76 million living individuals and roughly 294,000 deceased people — covering service members, reservists, civilian employees, contractors, veterans, retirees, and military family members. The root cause was a vulnerability in a file-sharing system, discovered and immediately patched Jul 16, 2026; the breach confirmation and public notification began Sep 29. Officials have found no evidence yet that the stolen data has been used maliciously, but note the database's details on military and civilian personnel work assignments carry national-security risk beyond typical identity-theft exposure. Affected individuals are being offered identity protection and credit monitoring. Durable catch: a nine-month gap between breach start (Oct 2025) and vulnerability discovery (Jul 2026) is the actual failure here — the fix, once found, was applied immediately, so the real lesson is about detection latency on a file-sharing system holding 60M+ personnel records, not patch speed.

CVE-2026-88771/88772 — third NetScaler zero-day pair of the year, exploited with documented IPs, hashes, and web-shell paths

Citrix disclosed two NetScaler ADC/Gateway zero-days, both CVSS v4.0 9.5: CVE-2026-88771, a command-injection flaw letting an unauthenticated attacker run commands via a three-stage chain (Base64-encoded dropper in the User-Agent header, log poisoning, then a Perl script launching a PHP web shell), and CVE-2026-88772, a DTLS memory-overflow flaw triggered by crafted DTLS packets that drops a .deb web shell. CISA added both to KEV Sep 27 with a Sep 30 deadline. Unit 42 published specific infrastructure IPs, file hashes, and web-shell paths tied to active exploitation — making this the rare entry where defenders get concrete artifacts rather than a bare CVE number. This is the third distinct NetScaler KEV entry in roughly six weeks (after CVE-2026-8452 and CVE-2026-19490). Durable catch: three independent NetScaler zero-days inside six weeks means any organization treating 'we patched the last one' as sufficient is already behind — NetScaler-adjacent monitoring needs to be continuous, not patch-and-forget.

ShinyHunters breaches FBI's jobs portal via an unpatched Oracle PeopleSoft flaw a contractor failed to fix, exfiltrates 2-3TB

ShinyHunters breached apply[.]fbijobs[.]gov starting the night of Sep 21-22 by exploiting an undisclosed Oracle PeopleSoft vulnerability that a third-party contractor had failed to patch despite an explicit patch being issued after a prior June 2026 exploitation wave — the contractor was subsequently removed. After gaining remote code execution without authentication, the group moved laterally into FBI-managed AWS GovCloud infrastructure and claims to have downloaded 2-3 terabytes of data; a sample shared with Reuters contained names, home addresses, Social Security numbers, duty assignments, and in some cases family members' names for current and former FBI personnel and job applicants. The FBI confirmed the breach, said it has already arrested multiple subjects with partners, and attributed the root cause directly: a contractor failed to implement a security patch explicitly issued to secure the platform. ShinyHunters says it targeted the FBI in retaliation for the bureau's May 2026 public advisory naming the group's tactics. Durable catch: a patch that exists and was explicitly issued but not applied by a third-party contractor is a vendor-management failure, not a vulnerability-research gap — any organization relying on contractors for platform maintenance needs to verify patch application independently rather than trusting contractor attestation.

Keio Corporation confirms ransomware attack disrupting payment and hotel systems at Tokyo rail operator's hospitality arm

Keio Corporation, a major private railway operator in Tokyo, confirmed a ransomware attack on its group servers Sep 26 and shut down its network to contain it. The attack disrupted payment systems and the hospitality business behind the group's roughly 25 hotels, including service delays and card-payment outages at properties like Keio Plaza Hotel Tokyo; core train operations were confirmed unaffected. Keio isolated its network, reported the incident to police, and engaged outside experts to trace the intrusion; as of Sep 28 no ransomware group had claimed the attack, and the company was still investigating whether customer or business-partner data was accessed. Durable catch: Keio's network segmentation held — train operations stayed up while hospitality/payment systems went down — which is the segmentation outcome every operator mixing safety-critical and customer-facing systems should be designing for, and worth confirming your own environment actually achieves rather than assumes.
