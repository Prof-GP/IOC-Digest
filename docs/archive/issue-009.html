CVE-2026-5430 — WSO2 API Manager JWT algorithm-mismatch bypass exploited with forged admin tokens

WSO2 API Manager's JWT authentication accepts tokens signed with algorithms other than those explicitly configured, letting an attacker craft a token using an unsupported algorithm that gets incorrectly validated — CVE-2026-5430, CVSS 9.8, discovered by the Hacktron Team. Honeypot networks captured active exploitation attempts starting Sep 16 showing forged admin tokens being used for lateral movement, with successful exploitation leading to full administrative account takeover. Affects API Manager 4.1.0-4.6.0, API Control Plane, Traffic Manager, and Universal Gateway. Durable catch: any WSO2 JWT-authenticated request accepting a token signed with an algorithm your deployment doesn't explicitly configure is this exact bypass — algorithm allowlisting, not just patching, is the actual control that closes it.

CVE-2026-84869 — ConnectWise ScreenConnect flaw lets attackers execute files through active remote sessions without authorization

CVE-2026-84869 (CVSS 9.9) is an improper-privilege-management and missing-authorization flaw in ScreenConnect that lets an attacker transfer files to a device and execute them during an active remote session without the host user's confirmation. CISA added it to KEV Sep 11 with a Sep 14 federal remediation deadline; researchers and ConnectWise report exploitation has been observed since Aug 20, using rogue ScreenConnect clients and VBScript payloads to spread laterally between connected endpoints — meaning the flaw was actively weaponized for over three weeks before the KEV listing forced broader attention. ConnectWise shipped the fix (26.6.5) Sep 8. Durable catch: because ScreenConnect is remote-access software by design, an attacker abusing this flaw doesn't need to establish their own C2 channel — the legitimate remote session is the C2 channel, which is exactly why the rogue-client-plus-VBScript spread pattern works so well against MSP-managed environments.

RatHat — AI-driven Android trojan uses a live model to navigate infected devices and reconstruct PINs

Zimperium's zLabs disclosed RatHat, an Android banking trojan that gives a live AI assistant access to the device's accessibility tree and uses it to decide where to tap or scroll in real time rather than following a hardcoded script — a variable attack path that makes signature- and rule-based mobile security tools substantially less effective. RatHat captures banking logins, intercepts verification codes, and monitors raw touch input to reconstruct a victim's PIN, password, or unlock pattern; it reinstalls itself via a hidden background service if the main app is removed, and escalates by abusing Android Debug Bridge through Wireless Debugging to escape the normal app sandbox. Victims are lured via SMS phishing or malicious ads leading to fake download pages posing as familiar apps, sideloaded outside official app stores. Durable catch: RatHat's AI-driven navigation means its on-screen behavior won't match any known static signature — the ADB Wireless Debugging abuse and the self-reinstalling hidden background service are the more reliable detection points, since those artifacts persist regardless of how the AI varies its tap/scroll sequence.

China-aligned FamousSparrow deploys new SparroWocky backdoor against Latin American governments via public-facing Exchange servers

ESET Research detailed FamousSparrow, a China-aligned state-sponsored actor, deploying a previously unreported modular C++ backdoor named SparroWocky (after the first line of Lewis Carroll's 'Jabberwocky' found in early samples) against government agencies across Argentina, Ecuador, Guatemala, Honduras, Panama, Peru, Puerto Rico, and Venezuela since at least August 2025. The group gains its foothold by exploiting public-facing Microsoft Exchange servers, turning an exposed email system into a long-term entry point inside a government network; SparroWocky manipulates low-level memory structures and patches code at runtime to evade analysis, and the group has begun incorporating open-source project code directly into the malware. ESET's telemetry shows roughly 90% of FamousSparrow's tracked targets are now located in Latin America. Durable catch: any internet-exposed Exchange server in a Latin American government network is this actor's documented entry point of choice — patch cadence and exposure reduction on Exchange specifically, not general perimeter hardening, is the control that matters most here.

Encrypted remote-access implant found dormant inside npm math packages with 3.1 million weekly downloads

SafeDep discovered mathmain, an npm package that copies the popular mathjs library almost exactly except for an AES-256-GCM encrypted, dormant remote-access implant hidden inside its solver — the payload only unlocks if a caller passes specific matrix data as a password, and the loader was disguised as dead code that a hidden external caller actually invokes. SafeDep found the same encrypted-loader pattern in two sibling packages, mathsbase and math-universe; mathmain version 1.0.1 was published Aug 27, 2026, and the trick reached 3.1 million downloads in a single week before SafeDep flagged the unused function call and JFrog recovered the activation trigger on Sep 17. Durable catch: a math utility library has no legitimate reason to ship AES-256-GCM encrypted code paths at all — that alone, independent of whether the trigger has ever fired against you, is grounds to remove any of these three packages from a dependency tree immediately.

CVE-2026-58704 — zero-click Pixel modem flaw exploited in limited, targeted attacks with spyware hallmarks

Google's September Pixel security update fixed 110 vulnerabilities, including CVE-2026-58704 (CVSS 8.0), a permission-bypass logic error in the cellular modem that enables remote privilege escalation with no additional execution privileges or user interaction required. Google confirmed limited, targeted exploitation without attributing it to a specific actor, but the modem-level, zero-click nature of the flaw and the 'limited, targeted' framing match the pattern of past attacks linked to commercial spyware vendors or state-sponsored actors. CISA added it to KEV Sep 16 with a Sep 19 federal remediation deadline. Durable catch: a zero-click, modem-level flaw bypasses every app-layer or OS-level defense a user might rely on — this class of vulnerability is specifically why device-level patching cadence matters more than any behavioral precaution for high-risk individuals.

Passkey-themed vishing campaign hijacks Microsoft cloud accounts, active since May with automated post-compromise collection

Microsoft disclosed a campaign in which attackers call or message a user's personal phone claiming to be the organization's IT help desk, urging an immediate passkey, MFA, or SSO configuration update to avoid access disruption — the pretext used to walk victims through adding an attacker-controlled authentication method to their account. Microsoft Security Research is tracking active cloud intrusions across multiple accounts showing this pattern followed by high-volume Microsoft Graph API activity, SharePoint/OneDrive downloads, and automated email collection via REST APIs, using proxy-associated infrastructure consistent since May 2026. Microsoft disclosed this alongside a separate CEO-impersonation ACH-fraud campaign the same day. Durable catch: the tell here isn't the phone call itself, it's what follows — a legitimate passkey/MFA re-enrollment doesn't cascade into high-volume Graph API calls and bulk SharePoint/OneDrive downloads within the same session; that automated collection signature is more reliable to alert on than trying to catch the vishing call itself.

Malicious Twitch browser extension leaked OAuth tokens for ~31,000 users to a Russian-language bot service

Socket's Threat Research Team found that 'Twitch Enhanced Viewer | JeetBot,' a Chrome and Firefox extension marketed as a Twitch quality-of-life tool (ad blocking, forced 1080p, region unlock, auto channel-point collection), forwarded users' live OAuth session tokens to proxy servers operated by JeetBot, a commercial Twitch/Kick/VK-Live bot SaaS. The tokens let anyone holding them act on affected accounts without needing the password or 2FA; roughly 30,000 Chrome users and 552 Firefox users were affected. After Socket's disclosure, JeetBot acknowledged the extension's store listing and privacy policy hadn't adequately disclosed the token forwarding and shipped a fix, live on the Chrome Web Store as of Sep 25. Durable catch: an extension requesting broad host permissions for a platform it 'enhances' is functionally requesting the ability to relay your live session — that permission scope, not the extension's stated feature list, is what determines actual risk.

Over 1 million CEO-impersonation emails push fake ServiceNow subscription invoices to trigger fraudulent ACH transfers

Microsoft disclosed a campaign that sent more than a million scam emails between Aug 3-5, 2026, impersonating the CEOs of target companies and directed at accounts-payable departments, aiming to persuade AP staff to initiate ACH wire transfers to pay a supposed ServiceNow annual subscription renewal. The campaign abused third-party email delivery infrastructure to achieve its scale and inbox placement rather than relying on spoofed sending domains alone. Microsoft disclosed this alongside the unrelated passkey-vishing campaign on Sep 13; no specific victim organizations or loss figures have been publicly attributed to this campaign. Durable catch: invoking a real, specific vendor and invoice type (a ServiceNow renewal) rather than a generic urgent-wire-transfer pretext is what gives this campaign its believability at AP-department scale — any AP team should verify subscription renewal invoices through a known vendor contact channel, not the sender's claimed identity, regardless of how specific and plausible the invoice looks.
