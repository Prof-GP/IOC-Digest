Joyfill npm packages hijacked — import-time RAT with blockchain C2

Malicious 2773-beta builds of @joyfill/components and @joyfill/layouts ship an obfuscated five-stage chain that runs the moment the module is imported, then resolves its C2 from a Tron transaction (pivoting to Binance Smart Chain) before opening a Socket.IO RAT and dropping a Python credential stealer. Payload executes at import time, so npm install --ignore-scripts does NOT stop it — the campaign marker A9-0135-3 and the C2 IPs are the durable catches.

CVE-2026-16232 — Check Point SmartConsole authentication bypass

An unauthenticated attacker with network access to a Check Point Security Management Server or MDS can read the server's SIC distinguished name over the bootstrap channel, replay it to log into SmartConsole with full administrator rights, and rewrite security policy. Tengu botnet — Mirai-derived Linux malware that reboots hosts to survive cleanup

A Mirai-derived, multi-architecture Linux botnet whose self-defense sets it apart: a guardian process re-checks the main binary every 60s, and it abuses the hardware watchdog so that killing the process forces a device reboot rather than a cleanup. Durable catch: a background process masquerading as [kworker/0:0] that reopens /dev/watchdog and sends keepalives — no legitimate userland process does this.

SourTrade — malvertising that makes the browser assemble the malware in memory

A malvertising operation impersonating TradingView, Solana and Luno serves no finished binary: its landing page pulls build instructions from /config, fetches a clean Bun runtime plus per-session AES-CTR bytes, assembles a unique Windows executable in browser memory, and hands it over through a ServiceWorker-controlled same-origin download. Every victim gets a different hash, so detection hinges on the /config build flow, the 96 domains, and the malicious JavaScriptCore bytecode in the PE's .bun section — not on a static hash.
